# sun-validate

太阳直射点、太阳高度角、晨昏线的验证工具。

## 算法

`data/SunPosition.kt`：天文年历低精度公式。

1. 由 Unix 毫秒算儒略日，`n = JD − 2451545.0`；
2. 平黄经 `L = 280.460 + 0.9856474 n`，平近点角 `g = 357.528 + 0.9856003 n`；
3. 黄经 `λ = L + 1.915 sin g + 0.020 sin 2g`，黄赤交角 `ε = 23.439 − 0.0000004 n`；
4. 赤纬 `δ = asin(sin ε · sin λ)`，赤经 `α = atan2(cos ε · sin λ, cos λ)`；
5. 格林尼治恒星时 `GMST = 280.46061837 + 360.98564736629 n`；
6. **直射点经度 = α − GMST**（规约到 ±180°）。

精度约 0.01°，对一张 720 像素宽的世界地图（每像素 0.5°）绰绰有余。

比 `SolarCalculator` 里那套 NOAA 日角式准得多——后者是给日出日落用的，赤纬误差最大 0.5°。

## 晨昏线为什么能解析求解

太阳高度角可以写成关于纬度的正弦函数：

```
h(φ) = R · sin(φ + ψ),   ψ = atan2(cos δ · cos H, sin δ)
```

其中 `H` 是该经线与直射点的经度差。所以某一条经线上的晨昏点就是 `φ = k·180 − ψ`，
在 [−90°, 90°] 之间最多两个，取中点的符号即可判定哪一段是夜。
夜半球永远只贴着一个极点（冬极），因此这段区间一定是一段连续区间。

## 验证

```
PYTHONPATH=. python3 compare.py
```

三件事：

1. **Kotlin ↔ Python 逐点比对**——`run-bench.sh` 把 `SunPosition.kt` 编到纯 JVM 上跑，
   6 个时刻的赤纬/直射点经度 + 117 个网格点的高度角，与 `sun.py` 比对。
2. **晨昏线回代**——把每列解出的边界纬度代回高度角公式，残差必须为 0。
3. **独立交叉验证**——新月时刻太阳与月亮的黄经必然相等。月球黄经那一套是拿
   7 次真实日月食校准过的（见 `../moon-validate`），所以用它的新月时刻反过来
   检验太阳黄经，是真正独立的检验而不只是自我复述。

当前结果：赤纬/经度/高度角偏差均 `< 0.0001°`，晨昏线残差 `0.000000°`，
新月时刻日月黄经最大差 `0.007°`。
